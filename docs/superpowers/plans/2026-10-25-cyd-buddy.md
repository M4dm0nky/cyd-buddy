# CYD-Buddy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Online-Agent) or superpowers:subagent-driven-development (lokal) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Nach jedem Task: Eintrag in `docs/FORTSCHRITT.md`, commit, push** (siehe „Fortschritts-Protokoll“).

**Goal:** Ein Schreibtisch-Wesen mit großen, ausdrucksstarken Augen auf dem ESP32-2432S028 (CYD2USB), mit Stimmungen, Touch-Gesten, Schlaf per Lichtsensor, Uhrzeit/Wetter-Laune, zwei Mini-Spielen und Online-Update über GitHub-Releases.

**Architecture:** Reine, am PC getestete Logik in `src/logic/*.h` (header-only, keine Arduino-Includes, Zeit als Parameter). Darum herum dünne Hardware-/UI-/Netz-Schichten (`src/hw`, `src/ui`, `src/net`, `src/ota`), die nur gebaut, nicht unit-getestet werden. `src/main.cpp` verbindet alles in einer Bildschleife; Netzabrufe laufen in einem eigenen FreeRTOS-Task.

**Tech Stack:** PlatformIO (pioarduino, Arduino-Core 3.x), LovyanGFX, WiFiManager (tzapu), ArduinoJson 7, Unity (native Tests), Node ≥ 20 für `tools/ota-publish.mjs`.

**Spec:** `docs/superpowers/specs/2026-10-25-cyd-buddy-design.md` – bei Widerspruch gilt die Spec.

## Global Constraints

- Display 320×240 quer (`setRotation(1)`); Augenbereich = 8-Bit-Sprite (RGB332) 320×200 = 64 000 B, darunter 40-px-Statusstreifen direkt gezeichnet.
- Kein PSRAM: keine Allokation > 64 KB, kein `heap_caps_malloc(..., MALLOC_CAP_SPIRAM)`.
- Partition `min_spiffs`, App-Slot 1 966 080 B; das Image muss kleiner sein.
- `src/logic/` = header-only, nur C/C++-Standardheader; jede Funktion bekommt `now_ms`/`dt_ms` als Parameter.
- Pins nur aus `src/config.h` verwenden (nicht neu definieren).
- UI-Texte Deutsch; Menü und Status mit **Symbolen** (gezeichnet aus Primitiven), keine Textkürzel; farbenfroh auf schwarzem Grund.
- OTA-Basis-URL: `https://github.com/M4dm0nky/cyd-buddy/releases/latest/download`, Dateien `manifest.json`, `firmware.bin`; erlaubte Hosts `github.com` und Endung `.githubusercontent.com`, nur `https://`.
- Kein `setInsecure()`, keine Zugangsdaten im Code.
- Tests: `pio test -e native -f <testordner>`; Gerät: `pio run -e cyd2usb`.
- Kein Release veröffentlichen, nicht flashen (macht der lokale Claude).

```cpp
#pragma once
#include <stdint.h>
#include "clamp.h"

// Bedürfnisse und Gefühl des Buddys. Reine Logik, Zeit kommt als Parameter (Host-Test test/test_mood).
enum class Emotion : uint8_t { CONTENT, HAPPY, BORED, SAD, SLEEPY, SLEEPING, SURPRISED, LOVE, ANNOYED, EXCITED, GREETING, COUNT };
enum class MoodEvent : uint8_t { TAP, STROKE, POKE, GAME_WON, GAME_LOST };
struct Needs { float affection, fun, energy; };
struct MoodState {
  Needs n;
  Emotion transient;          // CONTENT = keins
  uint32_t transient_until;
  uint32_t last_stroke_ms;
  bool stroked_once;
  bool napping;               // Nickerchen wegen Energie < 10
  bool dark;
  uint32_t dark_since;
};

constexpr float MOOD_AFFECTION_PER_MIN = -0.2f;
constexpr float MOOD_FUN_PER_MIN = -0.33f;
constexpr float MOOD_ENERGY_AWAKE_PER_MIN = -0.17f;
constexpr float MOOD_ENERGY_SLEEP_PER_MIN = 1.0f;
constexpr uint32_t MOOD_DARK_SLEEP_MS = 10000;
constexpr uint32_t MOOD_STROKE_COOLDOWN_MS = 2000;

inline void mood_clamp(Needs &n) {
  n.affection = clampf(n.affection, 0, 100);
  n.fun = clampf(n.fun, 0, 100);
  n.energy = clampf(n.energy, 0, 100);
}
inline void mood_init(MoodState &s, Needs start) {
  s = MoodState{};
  s.n = start;
  s.transient = Emotion::CONTENT;
  mood_clamp(s.n);
}
inline bool mood_daytime(int hour) { return hour < 0 || (hour >= 7 && hour < 22); }
inline bool mood_is_sleeping(const MoodState &s, uint32_t now_ms) {
  return s.napping || (s.dark && now_ms - s.dark_since > MOOD_DARK_SLEEP_MS);
}
inline void mood_set_transient(MoodState &s, Emotion e, uint32_t now_ms, uint32_t dur_ms) {
  s.transient = e;
  s.transient_until = now_ms + dur_ms;
}
inline void mood_set_dark(MoodState &s, bool dark, int hour, uint32_t now_ms) {
  if (dark == s.dark) return;
  const bool was_sleeping = mood_is_sleeping(s, now_ms);
  s.dark = dark;
  if (dark) s.dark_since = now_ms;
  else if (was_sleeping && mood_daytime(hour)) mood_set_transient(s, Emotion::GREETING, now_ms, 3000);
}
inline void mood_tick(MoodState &s, uint32_t dt_ms, uint32_t now_ms) {
  const float min = dt_ms / 60000.0f;
  if (mood_is_sleeping(s, now_ms)) {
    s.n.energy += MOOD_ENERGY_SLEEP_PER_MIN * min;   // im Schlaf nur Erholung, kein Abbau
  } else {
    s.n.affection += MOOD_AFFECTION_PER_MIN * min;
    s.n.fun += MOOD_FUN_PER_MIN * min;
    s.n.energy += MOOD_ENERGY_AWAKE_PER_MIN * min;
  }
  mood_clamp(s.n);
  if (s.n.energy < 10) s.napping = true;
  else if (s.napping && s.n.energy > 60) s.napping = false;
}
inline void mood_event(MoodState &s, MoodEvent e, uint32_t now_ms) {
  s.napping = false;   // jede Berührung weckt aus dem Nickerchen
  switch (e) {
    case MoodEvent::TAP: s.n.fun += 1; mood_set_transient(s, Emotion::SURPRISED, now_ms, 1500); break;
    case MoodEvent::STROKE:
      if (s.stroked_once && now_ms - s.last_stroke_ms < MOOD_STROKE_COOLDOWN_MS) break;
      s.stroked_once = true;
      s.last_stroke_ms = now_ms;
      s.n.affection += 8;
      mood_set_transient(s, Emotion::LOVE, now_ms, 4000);
      break;
    case MoodEvent::POKE: s.n.affection -= 3; mood_set_transient(s, Emotion::ANNOYED, now_ms, 20000); break;
    case MoodEvent::GAME_WON: s.n.fun += 25; s.n.affection += 5; mood_set_transient(s, Emotion::EXCITED, now_ms, 6000); break;
    case MoodEvent::GAME_LOST: s.n.fun += 10; break;
  }
  mood_clamp(s.n);
}
inline Emotion mood_emotion(const MoodState &s, int hour, uint32_t now_ms) {
  if (mood_is_sleeping(s, now_ms)) return Emotion::SLEEPING;
  if (s.transient != Emotion::CONTENT && (int32_t)(s.transient_until - now_ms) > 0) return s.transient;
  if (s.n.energy < 30 || (hour >= 0 && (hour >= 22 || hour < 6))) return Emotion::SLEEPY;
  if (s.n.affection < 20) return Emotion::SAD;
  if (s.n.fun < 25) return Emotion::BORED;
  if (s.n.affection > 70 && s.n.fun > 60) return Emotion::HAPPY;
  return Emotion::CONTENT;
}
// Zeit, in der das Gerät aus war, zählt wie Schlaf: nur Energie steigt.
inline void mood_apply_elapsed(MoodState &s, uint32_t seconds) {
  s.n.energy += MOOD_ENERGY_SLEEP_PER_MIN * (seconds / 60.0f);
  mood_clamp(s.n);
}
```
Hinweis: `SLEEPY` gilt 22–6 Uhr (Spec), das Begrüßen nur 7–22 Uhr. Zwischen 6 und 7 Uhr also weder schläfrig noch Begrüßung – gewollt (verschlafener Morgen kommt über Energie).

**Files:**

**Interfaces:**
- Produces:
```cpp
enum class Gesture : uint8_t { NONE, TAP, STROKE, POKE, LONG_PRESS };
struct GestureState { bool down; int16_t x0, y0, lx, ly; uint32_t t_down; float max_dist; float path; uint32_t win_start; bool long_sent; bool moved; uint32_t taps[5]; uint8_t ntaps; };
void gesture_init(GestureState &g);
Gesture gesture_feed(GestureState &g, bool pressed, int16_t x, int16_t y, uint32_t now_ms);   // ca. alle 20 ms aufrufen
```
Regeln: TAP beim Loslassen, wenn Druck < 300 ms und Abstand zum Startpunkt nie ≥ 15 px. Der 5. Tipp innerhalb von 3 s liefert **POKE statt TAP**, danach Zähler leer. LONG_PRESS einmal während des Haltens, sobald > 1200 ms und nie ≥ 15 px bewegt; danach liefert das Loslassen NONE. STROKE während des Haltens, wenn die Wegsumme seit `win_start` ≥ 60 px erreicht und `now - win_start ≤ 1500`; dann `path = 0`, `win_start = now`. Läuft das Fenster ab, ohne 60 px zu erreichen: `path = 0`, `win_start = now`. Nach Bewegung ≥ 15 px liefert das Loslassen NONE. Beim Loslassen (`pressed == false`) werden x/y ignoriert.
